# SSHNat 前端 UI 与操作逻辑优化方案

> 目标：在保留现有深色设计系统（`bg-base/bg-panel/border-edge/text-ink/text-dim/accent` 这套 token）的前提下，
> 用最小架构改动换取观感与操作效率的明显提升。按「投入小 → 收益大」排序。

---

## 一、现状诊断

| 维度 | 现状 | 问题 |
|---|---|---|
| 导航 | 左侧 68px/240px 竖向五栏（仪表盘/主机/隧道/日志/设置） | 合理，但仪表盘与隧道职责重叠（都能建隧道、都有隧道列表），信息被切成两处 |
| 仪表盘 | 5 个 KPI 卡 + 运行中隧道区 + 活动流 | KPI 均为纯文字卡，视觉平；「新建隧道」入口藏在这里而不是隧道页 |
| 隧道页 | 卡片/表格双视图 + 搜索/类型/状态过滤 | 成熟，但卡片操作（启停/编辑/删除/日志/复制命令）按钮多而小，误触风险 |
| 主机页 | 卡片 + 内嵌长表单（含高级选项） | 表单与列表同页滚动，主机一多就找不着表单；新增/编辑体验割裂 |
| 设置页 | 单列卡片堆叠 | 卡片之间层级一致，无分组感；页面偏长 |
| 反馈 | 错误用红条、成功用绿条 inline 展示 | 操作成功（复制、保存）没有瞬时 toast 反馈，错误也无统一收口 |
| 终端 | （本次新增）全屏遮罩弹窗 | 单会话单弹窗，无多标签 |

## 二、优化方案

### 1. 导航与信息架构（收益最大，改动中等）

- **合并「仪表盘」与「隧道」为「工作台（Overview）」**：上半部 KPI + 速率图，下半部即隧道列表（带现有搜索/过滤/双视图）。减少一次跳转，隧道管理成为主界面。
- 导航收敛为四项：`工作台 / 主机 / 日志 / 设置`。
- 侧栏底部速率区升级为**迷你实时折线图**（复用现有 Sparkline），比两个数字更直观。

### 2. 全局反馈系统（投入很小，体验提升大）

- 引入轻量 **toast 通知**（右上角滑入，3 秒自动消失）：
  - 成功：隧道已启动 / 主机已保存 / 命令已复制 / 配置已导入；
  - 失败：红色 toast + 「复制错误详情」按钮。
- 删除/替换等破坏性操作统一换成**确认对话框**（现有 `Dialog` 组件）替代 `window.confirm`，带危险色按钮与后果说明。

### 3. 主机页重构

- 新增/编辑主机改为**右侧抽屉（Drawer）或模态**，不再与列表同页混排；列表行内加：
  - 连通性状态点（最近测试成功=绿 / 失败=红 / 未测=灰）；
  - 「终端」「编辑」「删除」图标按钮 + 主按钮「测试连接」。
- 高级选项默认折叠为「高级」手风琴（现有 `details` 已具备，移入抽屉即可）。

### 4. 隧道卡片操作收口

- 卡片右上角只保留 **启停 Switch + 一个「⋯」菜单**（编辑 / 查看日志 / 复制 SSH 命令 / 删除），减少误触，视觉更干净。
- 重连中状态显示**下次重试倒计时**（事件里已有 `nextInMs` 字段，只差 UI）。

### 5. 视觉细节（纯 CSS/token，风险极低）

- 统一卡片 hover：`border-color` 过渡到 accent/40，增加可点击暗示；
- KPI 卡片加迷你 sparkline 背景或趋势箭头；
- 滚动条美化（webkit 窄条 + 透明轨道）；
- `text-dim/70` 这类三级灰统一收敛为两级，提升对比度（无障碍）；
- 页面切换加 120ms 淡入（`transition: opacity`），成本低、质感提升明显。

### 6. 终端体验升级（本次已加单终端，下一步）

- 支持**多终端标签页**：底部标签条，每个主机一个会话，可并排对比；
- 终端弹窗记住上次尺寸与字体缩放（Ctrl+滚轮缩放字号）；
- 会话异常退出时自动带「重连」按钮（已实现）。

### 7. 键盘与效率

- `Ctrl/Cmd+K` 命令面板：搜索并执行「新建隧道 / 跳转到主机 X / 启动隧道 Y」；
- `?` 快捷键帮助浮层；`g d / g h / g t / g l` 页面跳转；
- 隧道列表 `j/k` 移动选择、`Enter` 启停。

## 三、建议落地顺序

| 阶段 | 内容 | 预估改动 | 状态 |
|---|---|---|---|
| P0 | Toast 系统 + 确认对话框替换 `window.confirm` | 新增 1 个组件 + 替换约 6 处调用 | ✅ 已完成（Toasts + ConfirmDialog，隧道/主机删除、配置替换均已接入） |
| P1 | 隧道卡片「⋯」菜单收口 + 重连倒计时 | 1 个 Dropdown 组件 + TunnelCard | ✅ 已完成（bits-ui DropdownMenu；reconnecting 显示秒级倒计时） |
| P2 | 主机编辑抽屉化 + 状态点 | Hosts 页重构 | ✅ 已完成（表单移入 Dialog，卡片加连通性状态点） |
| P3 | 合并仪表盘与隧道为工作台 | 路由与视图合并 | ✅ 已完成（Workbench：KPI 概览条 + 隧道卡片/表格 + 过滤；导航收敛为 4 项） |
| P4 | 命令面板与快捷键 | 新增 CommandPalette | ✅ 已完成（Ctrl/Cmd+K；g w/h/l/s 跳转；面板内可建隧道、启停、打开主机终端） |
| P5 | 多终端标签页 | TerminalModal → TerminalDock | ✅ 已完成（底部 Dock：标签切换/折叠/最大化，跨页面常驻） |

> 附带完成：页面切换 120ms 淡入；启动/停止/删除/导入/导出/复制等操作均有 toast 反馈；破坏性操作全部改用统一确认对话框；
> 主题 token 重调（更深底色 + 卡片微光分层 + 径向光晕 + 细滚动条）；按钮/输入框焦点态升级；侧边栏激活指示条与命令面板入口。

## 3.1 已实现的附加改进（本轮）

- **原生文件按钮本地化**：配置导入改用自绘「选择文件」按钮，避免英文界面出现系统中文按钮；
- **私钥/known_hosts 选择器**：新增 `PathInput` 组件，调用原生文件对话框（`SettingsService.PickFile`）；
- **New Tunnel 弹窗**：顶部「表单填写 / 粘贴 SSH 命令」分段切换，Unix socket 字段折叠进高级区，私钥路径改为可浏览；
- **New Tunnel 可理解性**：类型切换带实时说明、命令预览可复制、目标主机快捷预设。

## 四、不建议做的

- 不引入路由库 / 状态库：现有 runes 驱动足够，引入框架级依赖得不偿失；
- 不做大改配色主题：现有深色系统完整且一致，只需收敛层级；
- 不追求图表库：Sparkline 已满足速率展示，避免为一次性的图表引入重型依赖。

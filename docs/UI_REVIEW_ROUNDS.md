## 第 3 轮：回归复检（修复后重新截图）

验证结果：

- 设置页：无重复标题、居中成列、全英文（含此前用户反馈的「选择文件/未选择文件」→「Choose File / No file chosen」）。

第 3 轮新增并已修复的点：

| 严重度 | 位置 | 问题 | 修复 |
|---|---|---|---|
| P1 | `TerminalPane.svelte` | 退出事件早于 `Open` 返回时会先清空 `sessionId`，`Open` 返回后又被覆盖成“connected”，形成已断开的空壳终端 | 连接期间的退出只记录到 `exitedSessions`（带错误文案），`Open` 返回后对账再决定 `exited` |

## 第 3 轮回归评审（正确性侧）追加修复

同轮的正确性评审（qa-round3）在最终快照上复核了 7 项修复并给出 3 条 P2，已一并修掉：

| 严重度 | 位置 | 问题 | 修复 |

## 结论

两轮视觉评审的全部 P1 与绝大多数 P2 已落地，正确性评审的 7 项复核全部通过、3 条 P2 也已修复。
